# ระบบจัดตารางสอนอัตโนมัติ (AI Timetable Scheduler)

เว็บแอปจัดตารางสอนอัตโนมัติ เขียนด้วย HTML / CSS / JavaScript ล้วน (ไม่ต้อง build)
เก็บข้อมูลใน **Supabase** และ deploy บน **Vercel** (ถ้ายังไม่ตั้งค่า Supabase จะบันทึกในเบราว์เซอร์แทนโดยอัตโนมัติ)

## ความสามารถหลัก

| ส่วน | รายละเอียด |
|---|---|
| นำเข้าข้อมูล | Excel (.xlsx), CSV (หลายไฟล์ หรือ ZIP), JSON, PDF ตามแม่แบบ · มีแม่แบบให้ดาวน์โหลด · ชุดตัวอย่าง เล็ก/กลาง/ใหญ่/มีข้อผิดพลาด |
| ตรวจข้อมูล | ช่องว่าง, รหัสซ้ำ, อ้างถึงข้อมูลที่ไม่มี, รูปแบบเวลาผิด, เวลาบังคับซ้อน, ห้องไม่พอ/จุไม่พอ, คาบเกิน 40, ครูชั่วโมงไม่ถึง 18 พร้อม "วิธีแก้" และคลิกไปยังแถวที่ผิด |
| พรีวิว | ดูข้อมูลที่ระบบอ่านได้ทุกชีตก่อนกด "ยืนยันข้อมูลนำเข้า" |
| จัดตาราง | ปุ่ม จัดตาราง / ยกเลิก / ลองใหม่ / เปิดดูผล · แถบความคืบหน้า 5 ขั้น · log · กราฟต้นทุน · คำนวณใน Web Worker (หน้าเว็บไม่ค้าง) |
| ตารางผลลัพธ์ | มุมมองกลุ่มเรียน / ครู / ห้อง · ค้นหาวิชา · ตรวจเงื่อนไข 18 ข้อ (ละเมิด ใช่/ไม่ + จำนวนครั้ง + จุดที่ละเมิด) · เทียบวิธีพื้นฐาน · ตัวชี้วัด (อัตราใช้ห้อง, เวลาว่างคั่น, ภาระสอนรายครู) |
| ส่งออก | PDF (A4 แนวนอน 1 ตาราง/หน้า มีช่องลงชื่อรับรอง, เปิดได้หลังกดยืนยันผล), Excel (สรุป + ตารางทุกกลุ่ม/ครู/ห้อง + รายการ + ภาระครู + การใช้ห้อง), CSV |
| ทำซ้ำผลได้ | seed + จำนวนรอบเดียวกัน ได้ตารางเดิมทุกครั้ง |

## อัลกอริทึม (เอเยนต์ Plan - Act - Check)

1. **Planner**: วิเคราะห์ข้อมูล แบ่งครูผู้สอน (กรณีระบุครูได้หลายคน) ให้ทุกคนได้ ≥ 18 ชม. หัวหน้า ≤ 24 ชม. แล้วเรียงรายการที่จัดยากก่อน (ทางเลือกน้อย, คาบยาว, ครูภาระมาก)
2. **Builder**: วางคาบแบบ Greedy เลือกช่องเวลาและห้องที่เพิ่มต้นทุนน้อยที่สุด
3. **Repairer**: Simulated Annealing + Min-Conflicts (ย้ายคาบ, สลับคาบในกลุ่มเดียวกัน, เปลี่ยนห้อง, เปลี่ยนครู, ย้ายไปตำแหน่งดีที่สุด) คำนวณต้นทุนแบบเพิ่มทีละส่วน (incremental) จึงเร็ว
4. **Inspector**: ตรวจผลแบบอิสระ (ไม่ใช้โค้ดของตัวจัด) ตามเงื่อนไข 18 ข้อ และคำนวณตัวชี้วัด

ฟังก์ชันต้นทุน: เงื่อนไขบังคับ 1,000/จุด · เวลาครูไม่สะดวก 8/คาบ · วิชาแยกหลายวัน 4/วัน · ครูประจำภาระห่างค่าเฉลี่ยเกิน ±2 ชม. 3/ชม. · เวลาว่างคั่นของนักเรียน 2/คาบ

ผลทดสอบกับชุดตัวอย่าง (seed 42):

| ชุดข้อมูล | กลุ่ม/ครู/ห้อง | คาบ | วิธีพื้นฐาน (ขัดแย้งบังคับ) | ระบบนี้ | เวลา |
|---|---|---|---|---|---|
| เล็ก | 4 / 6 / 8 | 128 | 148 | 0 | ~1 วินาที |
| กลาง | 10 / 15 / 14 | 317 | 393 | 0 | ~1.5 วินาที |
| ใหญ่ | 24 / 36 / 28 | 758 | 1,079 | 0 | ~4 วินาที |

## เวลาเรียนและการตีความเงื่อนไข

- จันทร์-ศุกร์ 08.00-17.00 น. คาบละ 1 ชม. พักเที่ยง 12.00-13.00 น. (8 คาบ/วัน, 40 คาบ/สัปดาห์) ไม่มีคาบหลัง 17.00 น.
- ข้อ 11: คาบของวิชาเดียวกันในวันเดียวต้องต่อเนื่อง · ข้อ 12: วิชาเดียวกันควรเรียนจบในวันเดียว
- วิชาเกิน 4 คาบ แบ่งเป็นช่วงต่อเนื่องไม่เกิน 4 คาบ (ไม่คร่อมพักเที่ยง)
- ห้องที่ตั้ง "ใช้พร้อมกันหลายกลุ่ม = ใช่" (เช่น สนาม) ใช้เรียนวิชาเดียวกันพร้อมกันได้ (ลูกเสือ)

## โครงสร้างไฟล์

```

js/samples.js         สร้างชุดข้อมูลตัวอย่าง
lib/                  JSZip, pdf.js (ไม่ต้องโหลดจากอินเทอร์เน็ต)

supabase/schema.sql   โครงสร้างฐานข้อมูล
tools/make-samples.mjs  สร้างไฟล์ใน samples/ ใหม่
test/                 สคริปต์ทดสอบ
```

## ติดตั้งและใช้งาน

### 1) ทดสอบในเครื่อง
```bash
python3 -m http.server 8080      # หรือ npx serve .
# เปิด http://localhost:8080
```
(ต้องเปิดผ่าน http server เพราะใช้ ES module และ Web Worker)

### 2) GitHub
```bash
git init
git add .
git commit -m "AI timetable scheduler"
git branch -M main
git remote add origin https://github.com/<ชื่อผู้ใช้>/<ชื่อ repo>.git
git push -u origin main
```

### 3) Supabase
1. สร้างโปรเจกต์ที่ supabase.com
2. SQL Editor → วางไฟล์ `supabase/schema.sql` → Run
3. Project Settings → API → คัดลอก **Project URL** และ **anon public key** ใส่ใน `js/config.js`
4. เลือกแบบใช้งาน
   - ต้องเข้าสู่ระบบ (แนะนำสำหรับส่งกรรมการ): ตั้ง `REQUIRE_LOGIN: true` แล้วสร้างบัญชีทดสอบที่ Authentication → Users → Add user (ติ๊ก Auto Confirm)
   - ไม่ต้องเข้าสู่ระบบ: ตั้ง `REQUIRE_LOGIN: false` และเปิดนโยบาย anon ใน `schema.sql` (แบบที่ 2)
5. แก้ `SCHOOL_NAME` และ `TERM_TEXT` ให้ตรงสถานศึกษา

### 4) Vercel
1. vercel.com → Add New → Project → Import repo จาก GitHub
2. Framework Preset: **Other** · Build Command: เว้นว่าง · Output Directory: `.`
3. Deploy แล้วส่ง URL + บัญชีทดสอบให้กรรมการ

### สร้างไฟล์ตัวอย่างใหม่ / ทดสอบตัวจัดตาราง
```bash
npm i jszip                      # ครั้งแรกเท่านั้น
node tools/make-samples.mjs
node test/run.mjs small,medium,large 4000000
```

## รูปแบบไฟล์นำเข้า (5 ชีต)

| ชีต | คอลัมน์ (* = จำเป็น) |
|---|---|
| ครู | รหัสครู*, ชื่อ-สกุล*, แผนก, ตำแหน่ง (หัวหน้าแผนก/ครูประจำ/ครูพิเศษ), ชม.ขั้นต่ำ (ว่าง=18), ชม.สูงสุด (ว่าง=หัวหน้า 24), สอนทุกวัน (ว่าง=ใช่ถ้าแผนกคอมพิวเตอร์), เวลาไม่สะดวก (`จ 08.00-12.00; ศ 13.00-16.00`), ประเภทเวลาไม่สะดวก (ถ้าเป็นไปได้/บังคับ) |
| ห้องเรียน | รหัสห้อง*, ชื่อห้อง*, ประเภทห้อง*, ความจุ, ใช้พร้อมกันหลายกลุ่ม |
| กลุ่มเรียน | รหัสกลุ่ม*, ชื่อกลุ่ม*, ระดับชั้น, แผนก, จำนวนนักเรียน, รหัสครูที่ปรึกษา |
| รายวิชา | รหัสวิชา*, ชื่อวิชา*, ท, ป, น, คาบต่อสัปดาห์ (ว่าง=ท+ป), ประเภทห้อง (ว่าง=ทฤษฎี), ห้องเฉพาะ, เวลาบังคับ (`พ 15.00-17.00`), ครูที่ปรึกษาเท่านั้น |
| การลงทะเบียน | รหัสกลุ่ม*, รหัสวิชา*, รหัสครูผู้สอน (หลายคนคั่นด้วย `,`), คาบต่อสัปดาห์ |

ชื่อชีตไม่ต้องตรงทุกตัวอักษร ระบบดูจากหัวคอลัมน์ได้ และรับหัวคอลัมน์ภาษาอังกฤษ (เช่น `teacher_id`, `room_type`) ได้ด้วย
